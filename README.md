# projetosprint5

## Título do Projeto:
Dashboard de Análise de Veículos Usados - Aplicativo Web Interativo

## Explicação:
Este projeto consiste no desenvolvimento de um aplicativo web interativo usando Streamlit para análise e visualização de dados de anúncios de vendas de carros usados. O objetivo é criar uma ferramenta que permita aos usuários explorar os dados de forma visual e interativa através de gráficos e controles dinâmicos.

Funcionalidades:
Visualizações Interativas:

Histogramas para análise de distribuição de variáveis
Gráficos de dispersão para identificar correlações entre variáveis
Cabeçalhos informativos com descrições do projeto
Controles Interativos:

Botões para gerar visualizações sob demanda
Caixas de seleção (checkboxes) para escolher tipos de gráficos
Interface responsiva e intuitiva
Recursos Técnicos:

Aplicativo web hospedado na nuvem (Render)
Interface construída com Streamlit
Análise exploratória de dados (EDA) em Jupyter Notebook
Gerenciamento de dependências com requirements.txt
